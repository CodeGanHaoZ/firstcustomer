# Pro 服务定价与 token 测算 V2

日期：2026-11-08。建议与实现默认值：**¥99／项目，一次购买覆盖一个产品、一个目标市场的一轮验证**，不自动续费。此价格是首轮付费试价，不代表已经验证的最优市场价格。

## 服务与购买

免费出海机会报告 → 程序生成当前范围的 Pro 价格 → 客户确认服务 → 付款校验 → 自动开通项目并入队。取消老板逐单批价、接待报价员反复起草提案和客户重复接受两套价格的流程。付款与开通使用程序校验，不依赖模型口头声称“付款成功”。

包含定位与验证计划、一份英文验证页、单渠道行动方案与素材、一轮真实反馈复盘。已有且有效的 Free 研究直接复用；页面和渠道素材来自同一次 Launch 输出，不重复计算为两个独立 Agent。公开发布和定位由客户确认；不承诺流量、线索或收入。新增市场、新一轮实验、广告支出、人工服务不包含在这次购买中。服务方错误修复不能要求再次购买。

研究样本跨度大，不能用平均数保证每单成本。失败任务也有消耗；预估通过统一重试准备覆盖，而实际账务直接累加每次调用，不再重复乘系数。本地没有足够的成功 Launch/Growth 全链路样本，因此这些环节使用代码限制与调用次数假设；没有为测算额外请求付费模型，也没有将示例模型的零用量当成真实成本。

实际路由：研究规划 Flash；研究证据综合默认 Pro（关闭思考）；定位默认 Pro（可能有推理输出）；Launch Flash（单次输出上限 4K，业务检查最多两次生成，另有通用格式重试）；Growth Flash（单次输出上限 2.5K）；客服 Flash。此前附件将研究默认视作 Flash、复盘视作 Pro，与当前代码不同。

研究综合每次最多 40 份检索资料、每份截取 1,200 字符，可补查一次；知识参考正文累计最多 8,000 字符。模型计费还包含系统提示、JSON Schema、来源字段、对话历史及重发上下文，不能只数最终报告字数。token 数不是字节数、文件大小或字符数。

## Pro 付费阶段增量预算

以下是每个项目本轮累计预算，不是每次调用的用量。定位已预留约两次调用，Launch 预留两次 4K 输出；统一再加 25% 给格式重试、异常与估算误差。补查为需要时使用的预留，不会因为购买就强制重做免费报告。

| 环节 | 模型 | 输入 token | 输出 token | 未命中实时 token 费用 |
|---|---|---:|---:|---:|
| 补查检索规划 | Flash | 10,000 | 2,000 | ¥0.014 |
| 证据补查与综合 | Pro | 100,000 | 16,000 | ¥0.396 |
| 定位与验证计划（含修改准备） | Pro | 30,000 | 12,000 | ¥0.162 |
| 英文页与单渠道素材（合并） | Flash | 36,000 | 8,000 | ¥0.052 |
| 一轮增长复盘 | Flash | 10,000 | 2,500 | ¥0.015 |
| 项目问答与客服准备 | Flash | 24,000 | 3,000 | ¥0.030 |
| **合计** | | **210,000** | **43,500** | **¥0.669** |

基础合计 **253,500 token**；含 1.25 重试准备后约 **316,875 token（31.7 万）**。其中输出已按包含推理消耗的预算计，不能在计费输出上再次叠加相同的 reasoning token。缓存命中按 0 估算，命中收益不作为维持售价的前提。

费率沿用用户附件版本 `mimo-cn-2026-09-22`：Flash 输入/输出 ¥1/¥2 每百万，Pro ¥3/¥6。全实时调用，不假设尚未实现的 Batch 调度折扣。官方参考：[MiMo 实时与 Batch 费率](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/batch-api)。

补查暂预留 12 次 × ¥0.0355 = ¥0.426，采用附件海外搜索 $5/千次、汇率 7.1 的预算。实际计费地区取决于接入服务，不由研究的市场语言决定；公开免费来源不得当作付费搜索。参考：[联网搜索说明](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/tool-calling/web-search)。

```text
Pro AI 增量预算 = (0.669 + 0.426) × 1.25 = ¥1.36875
加基础设施预算 = 1.36875 + 5 = ¥6.36875
```

## 免费阶段与经营分摊

完整服务还包括 Lumi 对话、截图理解和免费研究。示例预算：对话 36K/6K 输入输出，截图 8K/2K，研究任务累计 112K/15K；免费阶段合计 179K，含重试约 223.75K。与上述 Pro 增量合计约 **540.6K token（54 万）**，同一份研究不会在 Pro 中再执行一次。

按免费研究全部采用较贵 Pro 费率、对话与截图采用 Flash、25 次搜索都按附件海外费率付费的保守假设，免费阶段 AI 预算约 ¥1.716875。这是模型预算，不是本地样本的实际均值；本地成功研究任务的模型标价均值约 ¥0.3713，路由混合、免费检索和成功样本筛选都会影响比较。

为了不只给付费用户的 token 加价，默认加入 **¥40 经营准备金**：按约 5% 免费转付费率假设，免费资源分摊约 ¥34.34／单，再为客服、异常与维护预留约 ¥5.66。它不表示每单人工审核，也不是已发生支出。输入到计价配置的 ¥40 可随真实转化率和账单调整。

```text
内部预算 = AI 1.36875 + 基础设施 5 + 经营准备金 40 = ¥46.36875
默认价格 = max(99, ceil(46.36875 × 2)) = ¥99
```

¥99 扣除这份内部预算后余量约 ¥52.63；准备金和基础设施都是规划值，不能把这个差额当成已实现净利润。若其他费用超出准备，或 Free 付费转化只有 2%，单笔免费资源分摊会接近 ¥85.84，¥99 将缺乏足够余量，应优先收紧免费滥用和无效反复执行，再根据真实交付调整套餐。

## 实现边界

- 计价版本为 `mimo-cn-2026-09-22-service-v2`；金额使用整数分，成本使用纳元。
- token 是预算目标，当前不是对客扣费配额或硬上限。通用格式修复、客户多次修改、反复补查仍可能超过预算，应通过真实账单持续校准，不以估算值冒充实际值。
- 老板报价表单、旧客户接受报价操作和批价权限已移除。历史决策仍可审计，未付款提案转换时保留原订单 ID，递增版本并保存原提案、原价和旧版本。
- 已存在付款或付款凭证的订单不覆盖、不重复购买；原已接受的购买快照不因改价更新，付款仍校验原快照。
- 未付款旧状态直接提供相同的自助购买入口；已排队的起草报价任务恢复为报告完成，无新增模型调用。GET 页面展示不写库。
- 本次不更改现有付款校验通道，不新增数据库迁移。环境显式覆盖的价格优先于默认配置，部署前需核对目标环境。
