# 新用户免登录完整试用

日期：2026-11-08。新用户可免费体验 **1 轮完整 Pro 验证**，无需登录、付款或老板审批。试用包含定位、英文验证页、单渠道行动方案和增长复盘；定位和公开发布仍由客户确认。同轮修改、失败重试不扣新次数。

## 客户流程

1. 直接创建项目，完成免费的出海机会报告。
2. 在项目页点击「领取 1 轮免费试用并开始」，自动启动策略任务。
3. 从当前浏览器的试用工作台或项目专属链接返回，完成本轮验证。
4. 注册或登录为可选操作，用于归档成果和跨设备访问；导入试用项目时同时记录账号已使用试用，不另赠一轮。
5. 试用报告完成后，可自愿购买 **¥99／额外 3 轮**。试用轮不抵扣付费套餐。沿用同一项目，购买起始轮为第 2 轮，覆盖第 2–4 轮；没有自动收费或续费。

访客在当前浏览器限领一次；登录客户同时检查账号资格。免登录不能可靠识别自然人，清除 Cookie、换浏览器或设备可能绕过浏览器限制，不能对外承诺“每人仅一次”。已在不同浏览器领取的历史成果可归档到同一账号，保留成果；不会因此再发放新的试用资格。

浏览器工作台保存最近 12 个项目入口 30 天，项目本身不会在第 30 天自动删除；清除入口后需凭专属链接返回。注册后归档到账号，可跨设备继续。专属链接拥有项目访问能力，应作为私人链接保管。

## 数据和执行

- `fc_pro_trial_visitor` 是服务端生成的 32 字节随机身份 Cookie，HttpOnly、SameSite=Lax，生产环境使用 Secure，保存一年；数据库只记录其 SHA-256。不使用 IP 或设备指纹作为身份。
- 创建访客项目时建立浏览器身份；领取操作也兼容已有项目。GET 页面只查询，不创建身份、授权或任务。
- `pro_trial_claims` 保留浏览器哈希、可选账号、项目、订单与一轮零元快照；账号、浏览器和项目各有唯一索引。删项目/订单只清空关联，不恢复已有领取资格。
- 同一浏览器通过 PostgreSQL 事务级 advisory lock 串行领取，同一账号通过账号行锁串行领取；随后锁项目，核对未暂停、已完成 Free、无历史付款或凭证等条件。重复点击同一领取不再次入队。
- 保存零元 `trial_active` 订单、试用授权审计、项目授权与任务入队同事务完成，入队失败全部回滚。访客不能领取已经归属其他账号的项目；匿名操作仍须持有有效的项目专属凭据。
- 项目为 `pro_access_source=trial`，不改账号会员等级。每次执行和交付校验真实领取记录、项目、需求/范围版本及当前轮次；伪造一个项目来源字段不能开通。
- 注册归档与账号试用记录绑定同事务完成。已使用其他试用的账号仍可保留导入成果，原账号领取记录继续阻止再次领取；不能通过删除项目重置资格。
- 升级待付款期间保留原试用成果与访问权限，验证付款后才启动下一轮。试用订单不创建付款记录，不计外部付费订单和实际收入；实际模型成本仍计入经营成本。
- 当前入口另有每 IP 每小时 8 次的提交频率限制，沿用应用内存限流。多实例部署时这不是全站统一防刷；扩大试用前应结合实际消耗配置共享限流或验证挑战。

## 迁移与发布

先执行 `npm run db:migrate`，应用 `0015_customer_pro_trials.sql`、`0016_guest_pro_trial.sql`，再发布 Web 与 Worker。生产发布的只读迁移检查会阻止遗漏迁移的版本。本地验证已应用迁移；生产发布须按相同顺序执行，实际发布状态以生产迁移记录与 Vercel 部署状态为准。

## 预算变化

沿用现有计价底座，试用单轮预算为 210K 输入、43.5K 输出；含重试约 316,875 token，模型和搜索合计约 ¥1.36875。若额外按每个试用项目分摊 ¥5 基础设施，增量预算约 ¥6.37；加前面的免费分析预算约 ¥1.72，共约 ¥8.09。这是规划预算，不是实测账单；共享基础设施的边际成本还需实测。

赠送完整试用后，旧版 ¥40 准备金采用的免费转付费假设需要重新校准，不能直接据此宣称 ¥99 稳定盈利。内部可按 `免费分析成本/付费转化率 + 完整试用成本×领取率/付费转化率 + 付费三轮直接预算` 测算同一批用户，再核对真实账单、领取率、转化率和轮次使用率。价格暂沿用 ¥99／三轮；试用是单独的获客投入，不从已购买的三轮中扣除。

本地 17 个文件、291 项测试通过，类型检查和 ESLint 无错误（保留一条已有无关警告）。覆盖访客整轮交付、注册归档、账号/浏览器并发限领、删除后不恢复、入队失败回滚、历史权益保留，以及试用后另购并完成三轮。模型、支付均使用隔离替身，不代表真实模型账单或收款。

生产构建通过。另在独立临时 PostgreSQL 与本机生产服务器上，通过真实 HTTP 表单提交核对了匿名领取、重复点击、访客完成本轮后查看三轮报价、注册并归档成果、试用后进入付款页五项流程。没有登录前置拦截，未调用真实模型接口或生成实际收款；临时服务器和数据库均已移除。此项使用服务端页面与 React 流式内容解析，未将其称为完整浏览器视觉验证。
