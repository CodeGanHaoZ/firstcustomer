# 首客 V4.2 验收与路演

## 本机验收

| 范围 | 结果 |
|---|---|
| 代码检查 | 114 项测试通过，TypeScript、ESLint 和生产构建通过 |
| 办公室 | 桌面六个工位可进入真实详情。手机端 390 px 列表无横向溢出，断线和恢复均有反馈。老板待办与等待客户分开，工位可回看最近一次打回。COO 提醒运行超过 30 分钟的任务及超过 24 小时的老板待办 |
| 跨项目任务板 | 汇总所有项目的 Agent 任务与经营报告，支持状态筛选、分页和原始任务链接。项目可暂停、恢复或重试 |
| 隔离浏览器流程 | 通过 Linux Docker Compose 和 Caddy 的 HTTPS 入口建单、刷新恢复草稿。老板审批报价，客户接受后查看收款码。上传截图、核对后记账，再通过定位和发布双审 |
| 客户进度 | 区分排队、实际执行、暂停和待客户确认。上传截图后显示待核对，人工确认后展示实际到账金额。浏览器验证了 299 元报价与 289 元模拟到账分别显示 |
| 英文验证页 | 预览文案和截图固定到同一版本，新版双审前仍能访问旧公开版。旧审批被拒绝，截图随新版本公开。老板和爬虫的访问被排除，同一访客的两次请求只计一次。测试线索排除后，复盘为样本不足 |
| 交付与客服 | 交付清单展示定位、商业证据卡、英文验证页、渠道方案、增长复盘和结案状态。老板交付后客户确认验收。普通问题得到回复，退款投诉转给老板并记录人工回复 |
| 闸门记录 | 验证页的声明检查按版本记录通过或退回及理由。老板交付、客户修改意见及最终验收关联同一份复盘。经营台可查阅，脱敏卷宗 `07-log.md` 可导出 |
| 周报与卷宗 | 周报保存经营快照和老板决定。卷宗 ZIP 包含 00–08 共九份 Markdown，测试联系方式已脱敏 |
| 真实 MiMo | 在独立数据库用同一个新测试项目跑通初诊、报价、票据读取、定位、发布、复盘和测试验收。初诊采到 8 条实时证据，其中 3 条为反面证据。零流量时判为样本不足 |
| 部署与私密页 | PostgreSQL 健康、迁移成功退出、Web 和 Worker 正常运行。Caddy 将 HTTP 跳转到 HTTPS，经营台和客户链接返回 `no-referrer` 及禁止索引的响应头。作废链接后，旧入口、预览图和付款截图均不可访问 |
| 网页读取 | 验证了真实 HTTPS 读取与 Chromium 兜底。在受控的脚本页面中，允许加载页面脚本并提取渲染结果，拒绝访问 IPv6 映射写法的本机地址 |

浏览器验收使用独立数据库和模拟模型。测试订单、付款截图和留资只用于验证功能。现有项目没有被代为审批。

本机经营库已保存第 1 版公司宪章草稿。首份真实经营周报由 `mimo-v2.6-flash` 生成，包含 3 条建议，生成时外部实收和有效留资均为 0。公司宪章和周报决定等老板确认。

## 提交文案草稿

**项目名**　首客 FirstCustomer

**一句话介绍**　首客让一个人经营一支 AI 出海团队，帮有 MVP 的中国开发者研究英语市场、上线验证页并复盘首批用户反馈。

老板通过办公室启动任务、处理审批并查看执行记录。初诊后，前台出服务提案，财务室核对到账，再由策略、发布和增长工位接力。战略室可以带理由退回研究室补查，缺证据的声明会被拦截。定位和发布由老板把关、客户确认，任务和审批版本都留有记录。

首客分别记录两条经营结果。首客的第一单以老板确认的外部实收为准，客户的第一单以其验证页收到的首条有效线索为准。比赛版本已完成隔离环境的真实 MiMo 和 HTTPS 流程验收，公开网址和真实外部订单需在提交前补齐。
